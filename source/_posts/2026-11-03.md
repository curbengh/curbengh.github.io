---
title: CVE-2026-98432 mitigation on OpenWRT
date: 2026-11-03
---

Configure OpenWRT [fw4](https://openwrt.org/docs/guide-user/firewall/firewall_configuration#includes_2203_and_later_with_fw4) to drop IPv4 packets with [Options header](https://en.wikipedia.org/wiki/IPv4#Options).

<!-- more -->

Create a file in "/etc/custom-scripts/drop-ipv4-options.nft" or whichever preferred folder, as long as the folder is included in "/etc/sysupgrade.conf".

```
# https://almalinux.org/blog/2026-10-30-cve-2026-98432/#temporary-mitigation-if-you-cannot-reboot-yet
chain drop_ipv4_options {
  type filter hook prerouting priority -300; policy accept;
  meta l4proto tcp ip hdrlength > 5 counter drop comment "!fw4: Drop IPv4 packets with Options header CVE-2026-98432"
}
```

Existing raw_prerouting chain has similar hook and priority, but it doesn't support `include`.

Append to "/etc/config/firewall",

```
config include
  option type 'nftables'
  option position 'table-post'
  option path '/etc/custom-scripts/drop-ipv4-options.nft'
```

Then reload fw4.

```
/etc/init.d/firewall reload
```

LuCI web > Status > Firewall ("/admin/status/nftables") > Traffic filter chain "drop_ipv4_options"

Rule matches | Rule actions
--- | ---
\# 0 B IP protocol is TCP ip.hdrlength greater than 5 | Drop packet
